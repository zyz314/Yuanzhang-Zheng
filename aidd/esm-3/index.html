ESM-3

A generative protein language model that reasons over sequence, structure, and function.

What it does

ESM3 is a generative model of proteins. It can generate sequences, fill in masked regions, and condition on structure or function tokens.

It is not a wet-lab oracle. Generated proteins still need folding, expression, and functional validation.

The AI principle

ESM3 uses a masked generative objective over discrete protein tokens: amino acids, structure tokens, and function keywords. The largest released model has 98B parameters.

The model learns a joint representation of sequence, structure, and function. Conditioning on structure or function lets it generate sequences that are consistent with those constraints, rather than only predicting a masked residue.

What it is good at

  • It unifies sequence, structure, and function in one generative model.
  • It can be prompted with partial structure or function descriptions.
  • It is a strong foundation model for protein representation learning.

Where it breaks

  • Open weights are limited and the largest model is not freely available for all uses.
  • Generated proteins can be unstable or non-functional.
  • The model can reproduce training-set biases and does not guarantee novelty.

How I would improve it

  • Pair generation with folding and expression filters.
  • Add antibody- and enzyme-specific conditioning.
  • Report novelty and failure rates, not only perplexity.
