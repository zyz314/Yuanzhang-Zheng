Chemprop

The standard directed message-passing neural network for molecular property and ADMET prediction.

What it does

Chemprop predicts molecular properties from a 2D graph. It is widely used for ADMET, toxicity, solubility, and other endpoints.

It is a supervised model: it needs labeled data for the endpoint you care about. It is not a generative model.

The AI principle

Chemprop uses a directed message-passing neural network (D-MPNN). Messages flow along directed bonds, so the model can learn local chemical environments without hand-coded fingerprints.

A readout layer aggregates atom/bond representations into a molecule-level prediction. Modern Chemprop supports multi-task training, uncertainty estimates, and descriptor augmentation.

What it is good at

  • It is a strong, fast baseline for molecular property prediction.
  • The directed message-passing design is chemically sensible and data-efficient.
  • It has good tooling for uncertainty and multi-task endpoints.

Where it breaks

  • It is 2D and does not see the binding pocket or 3D conformation.
  • Performance drops on rare scaffolds and small datasets.
  • Uncertainty estimates need calibration and can be overconfident.

How I would improve it

  • Add 3D conformer or pocket context for mechanism-aware endpoints.
  • Calibrate uncertainty on scaffold splits and report applicability domain.
  • Use multi-task learning with biologically related endpoints.
