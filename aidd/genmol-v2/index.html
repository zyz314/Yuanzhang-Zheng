What it does

GenMol V2 is a repository update to GenMol, not a separately published model with its own paper. It extends the SAFE syntax and ships updated code/checkpoints.

I keep it as a separate page so the exact version used in a test is recorded. The underlying idea is the same discrete-diffusion generator described on the GenMol page.

The AI principle

The core is still masked discrete diffusion over SAFE fragments, with parallel decoding and fragment remasking. V2 changes the representation/syntax and the released checkpoint rather than introducing a new learning paradigm.

The practical AI question is version stability: a better tokenizer can improve fragment handling, but it also changes the distribution the model was trained on. Reproducing a result requires pinning the checkpoint and syntax version.

What it is good at

  • The extended SAFE syntax can represent more complex fragments and attachment patterns.
  • Updated checkpoints may improve generation quality without a new pipeline.
  • It is a useful reminder that model versions need to be recorded.

Where it breaks

  • There is no separate peer-reviewed paper for V2; the evidence is the repository and the original GenMol paper.
  • Version drift makes comparisons with published GenMol results difficult.
  • The same 2D limitations as GenMol apply.

How I would improve it

  • Publish a versioned model card with exact training data, tokenizer, and evaluation.
  • Run a controlled V1-vs-V2 comparison on identical prompts and metrics.
  • Keep backward-compatible checkpoints so published results can be reproduced.
