RFantibody

Structure-based de novo antibody and nanobody design with an antibody-finetuned RFdiffusion pipeline.

Year
2024
Difficulty
Advanced
Compute
NVIDIA GPU; substantial for 1,000+ designs
Status

Access note. MIT license; Linux, CUDA 11.8+, Docker/Apptainer supported. The README recommends pilot runs before large campaigns.

What it does

RFantibody is a three-stage pipeline: an antibody-finetuned RFdiffusion generates CDR loops and docks against an antigen, ProteinMPNN designs sequences, and an antibody-finetuned RF2 predicts the complex and supplies confidence scores.

It is built for de novo antibodies and nanobodies. It uses an HLT-format framework (heavy, light, target chains) and designs only the CDR loops specified by the user.

The AI principle

The first stage is a fine-tuned RFdiffusion model. It performs SE(3) diffusion over antibody frameworks and CDR loops, conditioned on the target structure and hotspot residues. The antibody-specific fine-tuning teaches the model natural CDR length and docking geometry.

The second stage is ProteinMPNN, which designs CDR sequences for the generated backbone. The third stage is an antibody-finetuned RF2 that predicts the antibody-antigen complex and provides pLDDT, pAE, and interface scores for filtering.

What it is good at

  • It is an open, end-to-end antibody design pipeline with a usable CLI, Quiver files, and Docker/Apptainer support.
  • It can design nanobodies and scFvs against a specified epitope.
  • It is built for scale: the README discusses campaigns in the thousands to tens of thousands of designs.

Where it breaks

  • The success rate is still low, and the authors note that the current RF2 filter is not reliable enough.
  • Typical campaigns may need ~10,000 designs to find hits; 2,000 is a pilot, not a guarantee.
  • It does not model developability, expression, immunogenicity, or affinity maturation.

How I would improve it

  • Replace or augment the RF2 filter with AF3/Boltz-2 and a calibrated ensemble.
  • Add developability and expression predictors before wet-lab ordering.
  • Feed experimental positives and negatives back into the filter and the design distribution.
