Uni-Mol

A 3D molecular pretraining framework for property prediction and downstream design.

Year
2023
Difficulty
Intermediate
Compute
GPU recommended
Status
Brief ready

Access note. General-purpose molecular representation baseline

What it does

Uni-Mol learns representations from 3D molecular conformations. It is a pretrained backbone for property prediction, conformer generation, and other downstream tasks.

It is not a generative model for new molecules by itself. It provides embeddings and task heads.

The AI principle

Uni-Mol uses an SE(3)-equivariant transformer over atoms and coordinates. Pretraining masks atoms and predicts their coordinates/properties, forcing the model to learn local geometry and chemical context.

The pretrained representation can be fine-tuned on ADMET, solubility, or other molecular properties. The key idea is that 3D geometry carries information that 2D fingerprints miss.

What it is good at

  • It captures 3D conformation, which is important for binding and property prediction.
  • The pretrained backbone can be fine-tuned with relatively little labeled data.
  • It is a strong baseline for 3D-aware ADMET and property tasks.

Where it breaks

  • It depends on the quality of the input conformer.
  • Pretraining data and task labels can introduce bias.
  • It is not a pocket-aware model unless conditioned on protein structure.

How I would improve it

  • Condition on protein pockets for target-aware property prediction.
  • Use conformational ensembles rather than a single conformer.
  • Calibrate uncertainty and test on scaffold splits.
